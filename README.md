# Long Course

An independent nutrition publication by Yiğit Aslan. Eleventy static site, Markdown content, GitHub Actions for scheduled publishing, Netlify hosting.

- Site: https://longcourse.netlify.app
- Owner guide: docs/owner-guide.md
- Editorial: docs/voice-guide.md, docs/editorial-plan.md, docs/inbox-policy.md
- Operations: docs/automation-register.md, docs/scheduled-tasks.md, ops/state.json

Local: `npm install`, then `npm run preview` (drafts visible) or `npm run build`. `npm run check` runs the pre-publish checks.
